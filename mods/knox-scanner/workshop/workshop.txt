version=1
title=Knox Scanner [B42] - Game Events for Discord, Bots and Overlays
description=[h1]Somebody out there is keeping score.[/h1]
description=Knox Scanner writes the big moments of your run to a small text file, one line the moment each happens. A one-line command posts those lines to a Discord channel. From there your friends can read along, and a bot, a stream overlay or your smart lights can react.
description=
description=[h2]What it reports[/h2]
description=[list]
description=[*][b]Deaths[/b], with days survived and zombie kills
description=[*][b]Bites[/b] and [b]bad injuries[/b]
description=[*][b]Towns[/b] you reach, and [b]landmarks[/b] you walk into: police stations, gun stores, the prison, hospitals, churches and the like
description=[*]The [b]helicopter[/b], the [b]power grid[/b] going down, and [b]storms[/b]
description=[*][b]Hordes[/b]: 40 or more zombies within 20 tiles
description=[*][b]Milestones[/b]: every 100 kills and every 7th day survived
description=[*]A [b]request key[/b] you can bind, for "play something" style triggers
description=[/list]
description=Every event has its own tick box under [b]Options, Mods, Knox Scanner[/b], next to a master switch. A short note above your character confirms each line, and that has a tick box too.
description=
description=[h2]Send it to Discord[/h2]
description=The game cannot reach the internet from a mod, so one small command runs outside it.
description=[olist]
description=[*]In Discord: Edit Channel, Integrations, Webhooks, New Webhook, Copy Webhook URL.
description=[*]Paste the URL over WEBHOOK_URL in the command for your system.
description=[*]Leave it running in a terminal while you play.
description=[/olist]
description=Mac and Linux:
description=[code]tail -n 0 -F ~/Zomboid/Lua/KnoxScanner.txt | while IFS= read -r line; do curl -s -H 'Content-Type: application/json' -d "$line" 'WEBHOOK_URL'; done[/code]
description=Windows PowerShell:
description=[code]Get-Content "$env:USERPROFILE\Zomboid\Lua\KnoxScanner.txt" -Wait -Tail 0 | % { Invoke-RestMethod -Uri 'WEBHOOK_URL' -Method Post -ContentType 'application/json; charset=utf-8' -Body $_ }[/code]
description=
description=[h2]Other things to plug it into[/h2]
description=[list]
description=[*][b]Discord bots.[/b] Any bot that reads the channel can keep a death counter, a leaderboard or a running story.
description=[*][b]Stream overlays.[/b] Follow the file from OBS scripts or Streamer.bot and fire an alert on a bite or a death.
description=[*][b]Smart home.[/b] Point the command at a Home Assistant webhook. Red lights on a bite. Flicker when the helicopter comes.
description=[*][b]A run journal.[/b] Append the lines to a spreadsheet for a timeline of every character.
description=[*][b]AI narration.[/b] Feed the lines to a language model and a voice. Ours is a two-host survivor radio show that breaks in when one of us gets bitten.
description=[/list]
description=Each line is JSON. It carries a ready Discord message and plain fields for everything else:
description=[code]{"username":"Knox Scanner","content":"\ud83d\udce1 horde | Muldraugh | day 12, 14:00 | A horde of about 45 zombies is closing in on a survivor.","kind":"horde","place":"Muldraugh","day":12,"hour":14,"text":"A horde of about 45 zombies is closing in on a survivor."}[/code]
description=The file is Zomboid/Lua/KnoxScanner.txt in your user folder. It carries no player or character names.
description=
description=[h2]Setup and multiplayer[/h2]
description=For Project Zomboid [b]Build 42.22[/b]. No required mods. In single player, enable it and go.
description=In multiplayer the mod runs on each player's own game and reports that player to that player's own file. The server only has to list it so players load it. It sends nothing over the network.
description=[b]Mod ID: KnoxScanner[/b]. Add it to the server's Mods list.
description=
description=[h2]Cost, limits and removal[/h2]
description=[list]
description=[*]One check per game minute, about 0.005 ms. The zombie count for hordes took 0.02 ms with 45 zombies nearby. No per-frame work.
description=[*]Town borders are rough rectangles. Outside them the place reads "the countryside".
description=[*]The first game minute of a character records a baseline and reports nothing.
description=[*]Tested with two real clients on a dedicated server: every event above except storms and landmarks, which have logic tests only. The helicopter check reads the game's own schedule. Nobody has confirmed that a multiplayer client receives that schedule.
description=[*]Every player's game reports the same helicopter, storm and blackout, so a shared channel sees repeats.
description=[*]Safe to add or remove. No items, no world data. Removal leaves the text file behind.
description=[/list]
description=The first gallery image is an illustration. The gameplay image uses a disposable test world: the horde was placed for the picture, and the note above the survivor is the mod's real one. The options image shows F9 bound to the request key. The key is unbound by default.
